# Showreel source

Source for the 16-second animated overview used at the top of the READMEs
(`static/showreel.gif`, `static/showreel-en.gif`) and the MP4s attached to the
GitHub release. Not part of any npm package.

Everything is procedural: one Canvas 2D page per cut, rendered frame by frame
with Playwright, encoded with ffmpeg, and a numpy-synthesized soundtrack.

## Requirements

macOS with the system fonts Apple SD Gothic Neo and SF Pro (via `system-ui`),
`ffmpeg`, Python 3 with `playwright` (Chromium installed) and `numpy`.

## Build

```bash
cd tools/showreel
./build.sh v3      # Korean captions  -> out/doltap-showreel-v3{,-music}.mp4, out/preview-v3.gif
./build.sh v3en    # English captions -> out/doltap-showreel-v3-en{,-music}.mp4
./build.sh all     # every cut (v1, v1m, v2, v3, v3en)
```

One cut takes about a minute. Outputs land in `out/` (ignored by git).

The README GIFs are made from the grain-free PNG frames (the MP4s carry film
grain, which makes GIFs several times larger):

```bash
ffmpeg -y -framerate 30 -i out/frames-v3/%04d.png \
  -vf "fps=12,scale=800:450:flags=lanczos,split[a][b];[a]palettegen=max_colors=96:stats_mode=diff[p];[b][p]paletteuse=dither=bayer:bayer_scale=5:diff_mode=rectangle" \
  ../../static/showreel.gif        # use frames-v3-en and showreel-en.gif for the English cut
```

## Files

| File | Role |
|---|---|
| `showreel-v3.html` | Current Korean cut (opening title + v1 story + music grid). Generated from `showreel-v1m.html` by `make_v3.py` |
| `showreel-v3-en.html` | English-caption variant, generated by `make_v3en.py` |
| `showreel.html`, `showreel-v1m.html`, `showreel-v2.html` | Earlier cuts: original 15 s, beat-nudged, dynamic |
| `render.py` | Playwright frame renderer (`renderFrame(i)` per frame) |
| `music.py`, `sfx.py`, `mix.py`, `audio.py` | Soundtrack synthesis and mix |
| `contact.py`, `tile.py`, `spectro.py` | Review helpers: contact sheet, tiles, spectrogram |

Captions are the `head.text` entries of the `SCENES` table in each HTML file;
timings are in `T`, `SCENES` and `CAM` next to it. The logo is embedded at build time from
`static/logo-512.png` (`logo.js`, generated, ignored by git).
